① 품목 선택
수량 패키지
② 장바구니 · 패키지별0개
P5→P25→P26 파지 → P27→P28→P29→P30 비움 → 되돌려놓고 P5. 주문 중 불량이 나오면 무게측정 후 자동 실행됩니다.
패키지 1개 = 포장 튜브 1개(뚜껑 열기 → 채우기 → 뚜껑 닫기). 최대 3개까지 담기고 종류는 섞여도 됩니다. 4개 이상이면 자동으로 나뉘며, 담을 때 패키지를 직접 고르거나 목록에서 P1/P2 드롭다운으로 옮길 수 있습니다.
패키지가 여러 개면 앞 패키지가 끝난 뒤 다음이 자동으로 시작됩니다 (한 패키지가 미완료로 끝나면 뒤는 중단).
패키지 안에서는 담은 순서대로 탐색합니다. 실행 중 다른 품목이 잡혀도 그 패키지에 남아있으면 즉시 포장, 불량(구멍)은 P7 폐기, 필요 없는 공은 원래 종류 슬롯으로 반납합니다.
